PayarMove Pay — Cross-Border Mobility Payments
Project: PayarMove Pay
Company: PayarMove Platforms Africa Ltd
Network: Stellar
Primary Asset: USDC
Target Users: Renters, vehicle owners/hosts, and mobility platforms
MVP Environment: Stellar Testnet



1. Project Overview
PayarMove is building a peer-to-peer vehicle rental platform designed to make mobility more accessible across emerging markets.
A key infrastructure challenge is enabling fast, affordable cross-border payments, rental deposits, and host payouts between renters and vehicle owners.
For example, a traveler visiting Kenya may want to rent a vehicle from a local host but have limited options for making a fast international payment. Traditional payment systems can introduce:
High transaction fees
Settlement delays
Regional restrictions
Limited payment methods
Difficult cross-border payouts
PayarMove Pay will address this by providing a Stellar-powered payment infrastructure layer for PayarMove's internal applications.
The initial MVP will enable a renter to make a payment in Stellar USDC, track the payment, and demonstrate the movement of funds through the PayarMove platform.
The longer-term vision is to evolve PayarMove Pay into a payment API for mobility, travel, rental, and marketplace businesses operating across emerging markets.

2. Product Goal
Build a simple cross-border payment infrastructure that supports the core rental payment lifecycle:
Create Rental → Generate Payment → Customer Pays → Payment Verified → Host Receives/Is Credited
The MVP should demonstrate how Stellar can reduce friction around international payments between renters and vehicle owners.

4. — PayarMove Payment Engine
Description
Build the core payment infrastructure that allows PayarMove to create, process, and verify rental payments using Stellar.
The payment engine should be designed as a reusable service that can eventually support other PayarMove applications and external platforms.
Required Functionality
The engine should support:
Creating a payment request
Associating payment with a rental
Specifying payment amount
Specifying Stellar asset
Generating a unique payment ID
Accepting customer payment
Monitoring Stellar transaction
Verifying payment
Updating payment status
Recording transaction hash

PayarMove Pay should be developed as a separate payment service layer, rather than tightly coupling Stellar functionality to the rental frontend.
This will make it easier to eventually expose the payment infrastructure through an API.
